# KH1-PS2ishTitleMenu
Restores the PS2 title menu font to KH1PC (kinda). Users of the work-in-progress Mod Manager rework should instead use `camsPatience/KH1-PS2ishTitleMenu:newmanager`, which adds Squaresoft branding as a config option instead of a seperate mod.

Font used is Century Gothic, weighted Bold for menu items and Semi-bold (iirc) for Square Enix text.

Conflicts with any mod that changes the game's logo or the main menu text items. Supports all western languages.
